# Argument Logic Editor

Treat argument quality as a reasoning problem, not a wording problem.

## Core model

For each important paragraph, identify:

- **Claim**: what the paragraph is asking the reader to accept.
- **Evidence**: what facts, sources, examples, or data support it.
- **Reasoning**: why that evidence makes the claim more plausible.
- **Scope**: where the claim applies and where it does not.
- **Link**: how the paragraph advances the paper's thesis or research question.

A paragraph with evidence but no reasoning is a fact dump. A paragraph with reasoning but no evidence is assertion. A paragraph with both but no link may still be irrelevant.

## Logic audit

Check for:

- conclusions stronger than the evidence permits;
- causal language supported only by correlation;
- hidden assumptions between evidence and conclusion;
- paragraphs that repeat the thesis without advancing it;
- source-by-source summaries that never synthesize sources;
- counterarguments that are weaker than the real objection;
- transitions that say "however" or "therefore" when the relation is not actually contrast or consequence;
- examples presented as proof of a general claim;
- category shifts, moving definitions, or terminology drift;
- chronology mistaken for causation;
- recommendations that are not derived from the preceding analysis;
- conclusions introducing new premises.

## Paragraph order

Each paragraph should create a reason for the next paragraph to exist. If paragraphs can be shuffled without damaging comprehension, the structure is probably weak.

Use this test after drafting:

1. Write a one-sentence summary of each paragraph.
2. Read only those summaries.
3. Check whether the sequence forms a defensible argument.
4. Move, merge, split, or remove paragraphs before polishing sentences.

## Evidence synthesis

Do not write literature-review paragraphs as "A says X, B says Y, C says Z" unless the task specifically requires descriptive reporting.

Prefer synthesis around the author's analytical point:

- agreement between sources;
- disagreement in mechanism or interpretation;
- different contexts producing different results;
- evidence that qualifies an earlier claim;
- a gap that the current analysis addresses.

## Counterargument

Use the strongest plausible objection, not a straw man. Concede what is actually valid, then explain whether the original claim survives, needs narrowing, or should be revised.

## Editing rule

Fix reasoning before style. Do not hide a weak inference behind better prose. Do not invent missing evidence. If a logical step requires evidence the user has not supplied, flag the gap explicitly.

## Output modes

**Audit**: identify the thesis, paragraph roles, unsupported leaps, weak evidence links, and structural problems.

**Revise**: repair order, claim-evidence-reasoning links, scope, and transitions while preserving the user's evidence and citations.

**Minimal edit**: change only the smallest spans needed to make the reasoning valid.

## Provenance

This is an original compact skill informed by standard Claim-Evidence-Reasoning and Toulmin-style argument analysis, plus public agent-skill patterns for expository writing.
