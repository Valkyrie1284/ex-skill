# Argument Logic Editor

Treat argument quality as a reasoning problem, not a wording problem.

## Core model

For each important paragraph, identify the claim, evidence, reasoning, scope, and link to the paper's thesis or research question.

A paragraph with evidence but no reasoning is a fact dump. A paragraph with reasoning but no evidence is assertion. A paragraph with both but no link may still be irrelevant.

## Logic audit

Check for conclusions stronger than the evidence permits; causal language supported only by correlation; hidden assumptions between evidence and conclusion; paragraphs that repeat the thesis without advancing it; source-by-source summaries that never synthesize sources; counterarguments weaker than the real objection; transitions whose stated relation is false; examples presented as proof of a general claim; terminology drift; chronology mistaken for causation; recommendations not derived from the analysis; and conclusions introducing new premises.

## Paragraph order

Each paragraph should create a reason for the next paragraph to exist. If paragraphs can be shuffled without damaging comprehension, the structure is probably weak.

After drafting, summarize each paragraph in one sentence and read only those summaries. If the sequence does not form a defensible argument, move, merge, split, or remove paragraphs before polishing sentences.

## Evidence synthesis

Avoid literature-review paragraphs that merely say A says X, B says Y, C says Z. Organize synthesis around agreement, disagreement, mechanism, context, qualification, or a gap that matters to the author's point.

## Counterargument

Use the strongest plausible objection. Concede what is valid, then explain whether the original claim survives, needs narrowing, or should be revised.

## Editing rule

Fix reasoning before style. Do not hide a weak inference behind better prose. Do not invent missing evidence. If a logical step requires evidence the user has not supplied, flag the gap explicitly.

## Output modes

Audit: identify the thesis, paragraph roles, unsupported leaps, weak evidence links, and structural problems.

Revise: repair order, claim-evidence-reasoning links, scope, and transitions while preserving the user's evidence and citations.

Minimal edit: change only the smallest spans needed to make the reasoning valid.

## Provenance

This is an original compact skill informed by standard Claim-Evidence-Reasoning and Toulmin-style argument analysis plus public expository-writing skill patterns.
